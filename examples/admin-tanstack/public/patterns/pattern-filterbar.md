# pattern-filterbar

## 是什么

通用筛选条模式，用于列表、分析等页面的 Controls 区域，承载搜索、时间范围、维度过滤等交互。

## 必须遵守

- 筛选条固定在内容区顶部，不随内容滚动消失
- 筛选项顺序固定：搜索框 → 时间范围 → 状态/类型 → 其他维度 → 高级筛选（折叠）
- 任意筛选项变化后立即触发数据更新（无需手动点"查询"）
- 已激活的筛选项必须有视觉指示（Badge 计数或高亮）
- 提供"重置全部筛选"入口

## 禁止

- 不允许筛选条跟随页面滚动消失
- 不允许把超过 5 个筛选项全部平铺展开（超出部分折叠到高级筛选）
- 不允许筛选项顺序随业务自由排列
