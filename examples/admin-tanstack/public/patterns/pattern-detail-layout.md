# pattern-detail-layout

## 是什么

详情页两栏布局模式，用于单条记录详情页（record-detail 场景），左侧主体 + 右侧面板的经典布局。

## 必须遵守

- 第一屏必须回答三个问题：这是什么（Summary）、当前状态如何（Status）、能做什么（Actions）
- 主体区（Main）占 2/3 宽度，侧边面板（Side Panel）占 1/3 宽度
- 操作按钮固定在 Header 右侧，不随内容滚动；侧边面板顶部固定，不随主体滚动
- 主体内容区支持选项卡切换（如：明细 / 附件 / 日志），默认展示最关键内容

## 禁止

- 不允许操作按钮分散在页面多个位置（统一在 Header 右侧）
- 不允许详情页嵌套另一个详情页（关联对象通过链接或抽屉展示）
- 不允许侧边面板内容随主体内容宽度改变而重排
