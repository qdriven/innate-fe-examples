# pattern-kpi-cards

## 是什么

KPI 指标卡组模式，用于 dashboard 和列表页的 Summary 区域，横向展示 3-5 个核心指标。

## 必须遵守

- 指标卡数量固定为 3-5 个，不允许超出或低于此范围
- 每张卡片必须有：指标名、当前值、单位、同比/环比趋势（上涨/下降）
- 趋势颜色语义固定：碳排放下降 = 绿色（好），收入下降 = 红色（坏）——跟随业务语义，不固定颜色方向
- 骨架屏与卡片数量保持一致，不出现数量跳变

## 禁止

- 不允许在一张卡片内放置超过 2 个指标（复合卡片需走 dashboard 特殊设计）
- 不允许省略单位（哪怕单位是"个"）
- 不允许趋势箭头和颜色脱离业务语义（红/绿不能仅根据数值正负决定）
