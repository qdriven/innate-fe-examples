# pattern-wizard-stepper

## 是什么

多步骤向导导航模式，用于多步骤提交流程（wizard）的步骤指示和导航，通常固定在页面顶部或左侧。

## 必须遵守

- 步骤编号、标题、完成状态三要素必须同时展示
- 已完成步骤：打勾 + 可点击回溯；当前步骤：高亮；未来步骤：灰色 + 不可点
- 步骤总数在流程开始前就固定，中途不可插入或删除步骤
- 每步保存草稿时有明确反馈（保存中 / 已保存）
- 最后一步提交前必须展示汇总摘要页（只读，所有步骤数据一览）

## 禁止

- 不允许步骤数量在流程中途动态变化
- 不允许跳过当前步骤的必填校验直接进入下一步
- 不允许仅将数据存在 localStorage（必须服务端持久化草稿）
