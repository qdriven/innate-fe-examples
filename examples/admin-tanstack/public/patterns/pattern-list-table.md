# pattern-list-table

## 是什么

分页数据表格模式，用于列表管理页的 Main 区域，支持排序、选择、批量操作和行内快捷操作。

## 必须遵守

- 空态必须有引导 CTA，文案格式："创建第一个 XXX"，不得只显示"暂无数据"
- 骨架屏固定 8 行，不随容器高度动态变化
- 批量操作栏只有在选中行时才出现（或高亮），未选中时隐藏
- 每行右侧提供操作入口（查看详情为优先动作），超过 3 个操作收入下拉菜单
- 列定义（columns）必须在组件外 memo，禁止在 render 内内联定义

## 禁止

- 不得在列表页内嵌套另一个独立列表（层级扁平化）
- 不得用无限滚动替代分页（除非明确设计要求）
- 不得让表格横向溢出内容区（固定列 + 横向滚动处理宽表格）
