# @innate/kids-playground-ui

用 `@innate/ink` 手绘视觉层重做的儿童学习桌面。桌面骨架借鉴 `wandesk-ui` 的多窗口模型，但这里是独立 iframe 插件，内容聚焦低龄学习：字母、数字、涂鸦和故事。

```bash
pnpm --filter @innate/kids-playground-ui dev
pnpm --filter @innate/kids-playground-ui build
```

在壳中查看：

```bash
pnpm dev --profile kids
# http://localhost:4020/plugins/kids-playground-ui
```
